# DUSQ - Round2 

## Environment Installation

Install the required dependencies by running:

```bash
pip install -r requirements.txt
```

## Program Execution

Run the following command to execute the program:

```bash
python main.py
```

Select the input CSV file when prompted.

## Output

The output will be automatically generated in a folder with the same name as the input CSV file, located in the same directory as the input file.
